# 🌸 "Эне Мээрими" (Pregnancy Period Portal)

Бул долбоор кош бойлуу аялдар үчүн маалыматтык колдоо көрсөтүүчү веб-сайт.

## 🚀 Проектти кантип запуск кылуу керек?

Проектти иштетүү үчүн компьютериңизде **Docker** жана **Docker Compose** орнотулган болушу керек.

### 1. Конфигурацияны даярдоо
Проекттин тамырында `.env` файлы бар экенин текшериңиз. Эгер жок болсо, аны түзүп төмөнкү маалыматтарды жазыңыз:
```env
COMPOSE_PROJECT_NAME=ene-meerimi
APP_PORT=8080
DB_PORT=5432
DB_HOST=db
DB_NAME=pregnancy_db
DB_USER=postgres
DB_PASS=secret
```

### 2. Контейнерлерди ишке киргизүү
Терминалдан проекттин папкасына кирип, төмөнкү буйрукту иштетиңиз:
```bash
docker-compose up -d --build
```
Бул буйрук керектүү имидждерди жүктөп, контейнерлерди түзөт жана фондо иштетет.

### 3. Проектке кирүү
Контейнерлер ийгиликтүү иштегенден кийин, браузерден төмөнкү дарекке кириңиз:
👉 **http://localhost:8080**

### 4. Администратордук кирүү (Default Admin)
Админ панелге кирүү үчүн: **http://localhost:8080/admin**
Маалыматтар базасы автоматтык түрдө инициализацияланат жана демейки администратор түзүлөт:
- **Логин:** `admin`
- **Пароль:** `admin123`

## ✨ Жаңы функционалдар (Жакында кошулган)
- **Мобилдик меню (Mobile-first):** Сайттын бардык беттери телефондо колдонууга ыңгайлуу жана адаптивдүү.
- **Валидация:** Админ панелде YouTube жана WhatsApp шилтемелерин киргизүүдө каталарды алдын-алуу механизми кошулган.
- **Админ Панель:** Периоддорду, этаптарды жана чеклисттерди толук башкаруу (CRUD).
- **Издөө (Search):** Сайт ичинен керектүү маалыматты тез табуу мүмкүнчүлүгү.
- **Чеклисттер:** Кош бойлуу аялдар үчүн керектүү буюмдардын жана иштердин тизмеси.
- **Интеграция:** YouTube видеолорун көрүү жана WhatsApp аркылуу адистерге түз байланышуу.
- **Коопсуздук:** Бардык формалар CSRF чабуулдарынан корголгон.

## 🛠 Пайдалуу буйруктар

- **Логдорду көрүү:**
  ```bash
  docker-compose logs -f
```

- **Контейнерлерди токтотуу:**
  ```bash
  docker-compose stop
```

- **Контейнерлерди толугу менен өчүрүү:**
  ```bash
  docker-compose down
```

- **Маалыматтар базасына кирүү (CLI):**
  ```bash
  docker-compose exec db psql -U postgres -d pregnancy_db
```

## 📂 Проекттин структурасы
- `public/` - Веб-сервердин кирүү чекити (`index.php`).
- `src/` - PHP логикасы (Кластар, Контроллерлор).
- `views/` - HTML/PHP шаблондор.
- `config/` - Конфигурациялык файлдар.
- `docker-compose.yml` - Инфраструктуранын сүрөттөлүшү.
